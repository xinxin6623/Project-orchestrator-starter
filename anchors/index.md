## positive/(正向样本)

### 2026-05-21-luding-chicken-curriculum.md
- 路径: anchors/positive/2026-05-21-luding-chicken-curriculum.md
- 类型: 校园实养动物项目式课程 / 小学低段
- 适用项目: 一年级下 / 5 课时×40min / 单一动物载体 / 科学+劳动+生态融合
- 优点: 三维目标与课标条目可逐条对应；教师手册"剧本式"四段环节模板（活动简述/组织实施/引导要点/注意事项）；低段认知适配方法论完整（非标准测量、比喻教学、严控复杂工具）；生命伦理铁律明确（严禁人工剥壳）
- 缺点: 强依赖校内实养资源；课时极紧；自然笔记创作时间偏紧
- 可参照维度: 课时结构 / 学段适配方法论 / 教师手册四段模板 / 学生手册"探究日记"形态 / 生命与安全嵌入方式 / 自然笔记七要素
- 来源: 北京海淀区第二实验小学当代校区"幸福+"生态科技课程
- 加入时间: 2026-05-21

### 2026-05-21-luding-chicken-doc.md
- 路径: anchors/positive/2026-05-21-luding-chicken-doc.md
- 类型: 课程评估文档 / 教研可行性分析范式
- 适用项目: 对已有课程方案做"可执行/不可操作"裁决；课标+认知发展理论双重论证
- 优点: 拒绝理由扎实（课标+发展心理学+教学规律+现实约束四类依据）；"工具/观察/流程/安全"四象限替代方案可直接落地
- 缺点: 不是完整方案；部分表述偏书面；未给出"评估流程本身"的方法论
- 可参照维度: 评估文档"建议+拒绝+优化"三段结构 / 拒绝理由的复合论证范式 / 课标锚定的单元分解方法
- 来源: 用户提供（教研评估文档）
- 加入时间: 2026-05-21

### 2026-05-21-alpaca-curriculum.md
- 路径: anchors/positive/2026-05-21-alpaca-curriculum.md
- 类型: 校园实养动物跨学科课程 / 小学中段+科学社团
- 适用项目: 二年级劳动课/四年级劳动课/二三年级科学社团差异化设计 / 4 单元 8 课时 / 模块化非闭环结构
- 优点: 模块化单元结构应对"教学不连续"约束；学段差异化做到目标/任务/思维三重分层；班级课与社团课实施边界清晰；行为编码表 (Ethogram) 的小学化引入；课堂突发应对预案完整
- 缺点: 8 课时分散，体验完整度依赖学校协调；社团门槛较高；54 页教师手册新手备课负担重
- 可参照维度: 跨学段课程体系定位 / 模块化单元结构 / 学段差异化设计文本 / 班级-社团边界划分 / "科技工具可选"明示 / Ethogram 小学化 / "我观察到……所以我猜……"句式 / 突发应对双栏结构 / 不投喂底线+科学原因
- 来源: 北京海淀区第二实验小学安宁分校"幸福+"生态科技课程
- 加入时间: 2026-05-21

### 2026-05-21-alpaca-doc.md

### 2026-05-21-deer-park-curriculum.md
- 路径: anchors/positive/2026-05-21-deer-park-curriculum.md
- 类型: PBL 真实驱动问题项目式课程 / 小学高段毕业课程
- 适用项目: 六年级毕业 / 4 阶段 80 分钟课时 / 跨学科 / 真实数据采集+建议书产出+模拟答辩
- 优点: PBL 真实驱动问题贯穿；科学严谨性扎实（多处"局限性"明示）；跨学科整合自然；仪式感与情感设计完整；扩展阅读高阶；教师手册逐字稿颗粒度
- 缺点: 实施门槛高（监控视频/红外测温/客座评委协调）；监控视频是核心数据源一旦不可调取易崩；高阶概念多对中位学生压力大
- 可参照维度: PBL 真实驱动问题设计 / "认知→探究→分析→表达"四阶段 / "分工协作不可替代"小组结构 / 跨组交叉分析方法论 / 科学局限性明示 / IMRAD 启蒙 / 模拟答辩+预设刁钻问题 / 毕业献礼仪式感 / 评价向落地性对齐
- 来源: 北京海淀区第二实验小学橡树校区"幸福+"生态科技课程
- 加入时间: 2026-05-21
