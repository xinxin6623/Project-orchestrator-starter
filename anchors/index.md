## 维护节奏

- 每完成一个 C 级 Run,Supervisor 会主动询问是否将产出加入 positive/
- 季度 review:删除明显过时或低质量条目
- 外部样本(PDF / 网页 / 图片)需先转为 markdown 摘要再入库,顶部标注原始格式与来源
