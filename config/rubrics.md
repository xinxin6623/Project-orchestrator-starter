# 通用评价标准模板

> 仅在以下情况使用:
> - constraints.md 中 `review_mode: rubric_only`
> - constraints.md 中 `review_mode: hybrid`(双轨)
> - 某次 Run 中 `anchor_status: skipped`(替代 Anchor 的兜底)

## 必含要素(任何教育方案都应满足)
- [ ] 明确的目标对象(年级、学情)
- [ ] 可操作的活动设计(非口号)
- [ ] 安全与风险提示
- [ ] 评价方式说明
- [ ] 资源清单(场地、材料、时长、人员)

## 加分项
- [ ] 地方特色融入
- [ ] 跨学科衔接
- [ ] 家校协同设计
- [ ] 差异化处理(对内向学生、特殊需要学生等)

## 减分信号(出现即扣分)
- 大段政策原文搬运未做转化
- 套话占比超过 20%(以"立德树人""五育融合"等高频口号计)
- 缺少具体时长、人数、材料等可执行参数
- 评价方式只说"过程性评价"而无具体观察指标
- 安全风险未提及

## 自查输出格式

```markdown
# Rubric 自查报告

⚠️ 本项目缺少 Anchor / 使用 rubric 模式,验收可信度可能下降。

## 必含要素核验
- [✓] xxx
- [✗] xxx ← 需补充

## 加分项命中
- [✓] xxx

## 减分信号扫描
- [✓] 未出现 xxx
- [✗] xxx ← 需修改

## 用户需要裁决
- [ ] xxx 是否接受?
```
