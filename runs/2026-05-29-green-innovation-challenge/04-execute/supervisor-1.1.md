# S1 · 整体框架与价值主张

## 真实驱动问题（Anchor 维度 #2 映射）

> "作为绿光森林科技公司的小成员，我们如何用一块光伏板、一个废旧饮料瓶和安全的 UV-A 光，为学校的户外课堂打造一盏不用电、不喷药、能看见绿色能源在工作的驱蚊灯？"

贯穿规划书和视频的叙事主线。

## 核心价值主张（一句话）

> "阳光宝灯"不是一盏灯，是一堂可以动手参与的绿色科技课——用废旧材料造硬件、用真实数据证原理、用商业计划练思维。

## 叙事线设计（三幕递进）

| 幕 | 主题 | 对应评分维度 | 关键锚点 |
|----|------|------------|---------|
| **第一幕：从回收到创新** | 废旧材料改造 → 产品诞生 | 产品设计(40%) + 绿色环保(20%) | 3R 标注 / 废旧材料故事 / 可操作性证明 |
| **第二幕：从制作到探究** | LCD 数据 → 科学验证 | 创新意识(20%) + 绿色环保(20%) | 光伏探知园数据对比 / 科普三概念 / 光催化原理 |
| **第三幕：从产品到商业** | 5P 商业计划 → 社会价值 | 商业计划(15-20%) + 视频制作(15%) | 成本双轨 / 竞品差异化 / 视频脚本框架 |

## 5P 结构骨架

| P | 核心内容 | 负责 Worker |
|---|---------|-----------|
| Product | 产品功能 + 3R 原则显式标注 + 特色优势表 | W1 |
| Price | 成本双轨表（单件 ¥107.50 / 量产 ¥71.50）+ 建议零售价 ¥159 + 利润分析 | W2 |
| Place | 校园义卖 / 家委会团购 / 社区科普集市 / 学校公众号 | W2 |
| People | CEO/CTO/CFO/CMO 四人分工 + 指导教师 | W5 |
| Promotion | 宣传语 + 海报 + 视频 + 校园/社区活动 | W5 |

## 语言规范（五年级统一）

- 不出现"范式""赋能""闭环"等成人化术语
- 科学概念用"类比+数据"双层表述：类比让理解，数据让信服
- 段落控制在 5-8 句，避免大段文字墙
- 表格优先于段落（评委快速浏览友好）
- 所有数字标注单位，数据来源可追溯

## 各 Worker 边界

| Worker | 负责 | 不负责（留给其他 Worker 或 Supervisor） |
|--------|------|---------------------------------------|
| W1 | 产品功能描述 + 3R 标注 + 特色优势表 + 工作原理 | 不写原材料清单（W5）、不写成本（W2）、不写光伏原理深入（W3） |
| W2 | 5P 完整段落 + 竞品对比表 + 成本双轨 + 消费者选择论证 | 不写宣传语定稿（W5）、不写视频脚本（W4） |
| W3 | 光伏数据联动方案 + 科普三概念 + 气象站对接 + 光伏原理小学生版 | 不写产品功能（W1）、不写视频展示形式（W4） |
| W4 | 视频脚本框架（四段式精确到秒）+ 画面/口播对照表 + 记忆锚点 | 不写产品演示内容本身（W1）、不写答辩预设（W6） |
| W5 | 人员分工详表 + 原材料清单（含采购渠道建议）+ 安全提示 + 宣传语定稿 | 不写竞品对比（W2）、不写科普概念（W3） |
| W6 | 答辩预设清单 + 服务人群聚焦 + 提交自查清单（对标附件二/三） | 不写视频脚本（W4）、不写 Rubric 自查（S3） |

## 设计意图

> **设计意图**：S1 框架的核心作用是保证 6 个 Worker 产出不会互相矛盾或重复。数据锚点锁定关键参数一致性；语言规范保证最终整合时不需要大量改文风；Worker 边界表明确"你写什么、不写什么"，减少 S2 衔接工作量。三幕叙事线来自 Anchor #2 "真实驱动问题贯穿"的映射——让规划书不只是信息罗列，而是有一条读者可跟随的故事线。
