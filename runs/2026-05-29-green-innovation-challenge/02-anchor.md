## 最佳候选：鹿园 PBL 课程（2.5/4）

### 命中维度

| 维度 | 分析 |
|------|------|
| **audience_match** ✓ | 六年级 vs. 五年级，仅差 1 年，同属小学高段，均处于形式运算过渡期。认知水平、团队协作能力、数据推理能力高度接近 |
| **structure_comparable** ✓ | 鹿园四阶段（认知→探究→分析→表达）与视频四段式（问题→方案→演示→展望）同构；"模拟答辩+预设刁钻问题"与比赛"产品展示+评委提问"同构；"IMRAD启蒙"与规划书"产品功能/特色/优势"结构化论述同构 |
| **type_match** △ | 课程方案 vs. 比赛方案，类型不同。但存在深度结构映射：PBL "学生作为守护者/贡献者" → 比赛中"学生作为公司成员"；"真实驱动问题贯穿" → 产品需要解决"真实痛点"；"建议书三段式" → 规划书 5P 结构 |
| **time_budget_feasibility** △ | 鹿园 4×80min vs. 比赛 5min 视频+规划书，时长不可比。但"每阶段设产出锚点+阶段性验收"的时间管理方法论可直接迁移到视频分段脚本设计 |

### 可参照的具体维度

从鹿园方案中提取 6 个可直接参照的维度：

| # | 维度 | 鹿园做法 | 阳光宝灯映射 |
|---|------|---------|------------|
| 1 | **科学严谨性明示** | "体表温度≠核心体温""相关性≠因果性""坐标轴诚实性"三处明示局限 | "阳光宝灯"LCD 数据标注测量误差范围；光伏发电效率受天气/角度影响做显式说明；光催化驱蚊"模拟呼吸"的类比边界注明 |
| 2 | **真实驱动问题** | "作为鹿苑守护者，如何为学校留下有数据支撑的专业建议？" | "作为绿光森林科技公司的成员，我们如何用废旧材料+太阳能，为校园劳动课打造一款安全、绿色、能看见数据的驱蚊灯？" |
| 3 | **分工不可替代性** | 4 组各负责不可替代的数据采集，阶段三跨组交叉分析 | CEO/CTO/CFO/CMO 四人分工不可替代，视频中每人有独立的"高光时刻"段落 |
| 4 | **模拟答辩设计** | 预设刁钻问题清单（"你怎么知道鹿热不热不是因为太阳晒的？"等） | 预设评委可能质疑（"UV-A 真的安全吗？""小学生能焊电路吗？""这个成本家长愿意买吗？"）并在规划书/视频中提前回应 |
| 5 | **仪式感与情感锚点** | 毕业献礼：建议书 + 实体提示牌 | 视频结尾：产品点亮仪式 + 全组喊出宣传语 + "一个废旧饮料瓶的科技蜕变"故事线收束 |
| 6 | **评价向落地性对齐** | 建议书评量表（数据支撑/逻辑链条/表达清晰/团队协作）直接对应课程目标 | 规划书自查清单直接对应附件二/三评分标准，逐条标注权重 |

### 不适配的部分（需补充的手段）

- 鹿园是"4 周长周期课程"，比赛是"单次提交+视频"，缺少**竞品分析**和**商业计划（5P）**维度 → 补充手段：rubric 模板中的"商业计划"核验项
- 鹿园无"原材料/成本/定价"等产品化内容 → 补充手段：constraints 中 `review_mode: hybrid` 双轨，Anchor 提供"严谨性+叙事结构"，Rubric 提供"完整性核验"

## 建议方案：双轨（Anchor 部分命中 + Rubric 兜底）

```
review_mode: hybrid（已在 constraints.md 支持）
├── Anchor 轨: 鹿园 PBL 课程 → 科学严谨性 / 分工设计 / 叙事结构 / 答辩预设
└── Rubric 轨: config/rubrics.md → 商业计划完整性 / 安全风险 / 资源清单 / 减分信号扫描
```

### 适配性未达标说明

`require_anchor: true` + `anchor_fitness_threshold: 3`。鹿园适配性 2.5/4 < 3。按 config 规则，Supervisor 必须警告：

> ⚠️ Anchor 库中无完全匹配的"比赛方案"类型样本。当前最佳候选鹿园 PBL 课程在 audience_match 和 structure_comparable 两个维度命中，type_match 和 time_budget_feasibility 部分命中。采用 hybrid 双轨模式（Anchor 提供结构参照 + Rubric 提供完整性核验），验收可信度比纯 rubric 模式更高，但低于有完全匹配 Anchor 的 Run。

**风险**：
1. 商业计划（5P）完整性和竞品分析段落的验收缺乏对标样本，只能靠 rubric 核验项兜底
2. "比赛方案"这一类型在 anchor 库中是结构性盲区（与碳十友 Run 相同）
3. 如果后续还有类似比赛方案任务，本次产出可作为"比赛方案"类型的首份 anchor 入库
