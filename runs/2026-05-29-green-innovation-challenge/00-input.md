# 原始输入

## 来源 1：比赛通知

北京市第十二届小学生绿色创新挑战赛，由北京教科院课程教材中心与 JA 中国联合举办。

- 参赛对象：北京市各区小学四至五年级学生，每校 4 名学生 + 1 名指导教师
- 初赛截止：6 月 16 日前提交"创新产品规划书"
- 决赛：9 月 24 日前提交 5 分钟展示视频
- 评分标准（初评）：产品设计 40% / 绿色环保 20% / 商业计划 15% / 创新意识 20% / 其他 5%
- 评分标准（终评/视频）：产品设计 20% / 绿色环保 20% / 创新意识 20% / 商业计划 20% / 视频制作 15% / 其他 5%

## 来源 2：原始产品规划草稿

"阳光宝灯"——手提式光伏驱蚊照明一体灯，含光伏发电、光催化驱蚊、暖光照明、LCD 数据监测、USB 应急充电功能。草稿已覆盖产品功能、3R 环保原则、服务人群、原材料、人员分工、宣传语。

## 来源 3：对齐问卷（duiqi）勾选结果

18 条决策点汇总：

| 维度 | 用户选择 |
|------|---------|
| 产品名称 | "阳光宝灯——手提式光伏驱蚊照明一体灯"（主+副标题） |
| 公司名称 | 绿光森林科技公司 |
| 角色分工 | CEO + CTO + CFO + CMO |
| 3R原则 | 显式标注 Reduce/Reuse/Recycle 评分关键词 |
| 服务人群 | 校园劳动课（主）+ 家庭露营/社区纳凉（辅） |
| 原材料 | 确认科技核心件淘宝可买 |
| 5P商业计划 | 全部覆盖（补 Place 渠道 + Price 定价策略） |
| 成本核算 | 双轨制：单件打样 + 量产50件+对比 |
| 宣传语 | 保留现有主副宣传语 |

| 区县/学校 | 最后填 |
| 视频脚本 | 四段式 + 纪录片跟拍混合 |
