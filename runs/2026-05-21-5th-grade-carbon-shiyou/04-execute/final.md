## §1 课程定位

### 1.1 一句话叙事

> 在自己最熟悉的校园里，用"**看见 – 测量 – 行动**"三步，把抽象的"低碳"变成可触摸、可记录、可改变的具体行为。

### 1.2 设计哲学

1. **从"宏大叙事"回到"具体行动"**: 不讲"全球变暖危机"，不说"我们要保护地球"，而是引导学生发现"我们班今天午饭剩了多少？这些剩饭等于多少碳？"——把抽象议题坐落到学生当天的真实行为。
2. **拒绝口号化与套话**: 不写"立德树人""五育融合"等高频口号；每个活动环节都有可观察、可记录、可比较的具体指标（千瓦时、克、棵、份）。
3. **校园文化中性处理**: 学校所在社区有许多家庭对能源问题有天然敏感度——这一点作为校园文化底色保留，但**不作为叙事主线**。如老师认为需要完全删除，可去掉这一句不影响方案成立。

### 1.3 不解决什么（边界声明）

- ❌ 不要求学生掌握"碳达峰/碳中和"专业术语
- ❌ 不依赖特殊设施（无智慧农场、无 AI 传感器、无监控视频）
- ❌ 不强制家长配合（SMART 承诺自愿、不要求家长签字）
- ❌ 不评比、不打分排名

## §3 课程总览

### 3.1 学情前提（一定要读）

5 年级学生（10-11 岁）正处于**具体运算后期向形式运算过渡**：能进行简单逻辑推理但抽象概念必须挂载具体物。我们在课中要注意：

- **抽象概念给实物锚点**：碳 → 一棵树年吸 18kg、一辆车开 100km 排 20kg
- **节奏每 25-30 分钟切换**：纯讲解 ≤15 分钟，超过必插入身体活动
- **同伴影响 > 师生影响**：4 人异质小组 + 强制角色卡（记录员/计时员/汇报员/采访员），中途至少轮换一次
- **道德双标敏感**：教师/学校必须先做可见低碳承诺，否则学生用沉默抵抗
- **从校园可见现象切入**：不要用"北极熊/冰川融化"开场，5 年级对远距离物种共情有限

### 3.2 5 个常见前概念（开场必先破）

| 学生想法 | 真实情况 |
|---------|---------|
| "低碳就是少呼吸" | 呼出 CO₂ 来自吃的食物，在自然碳循环内 |
| "植树越多越好，能解决一切" | 一棵树年吸碳量有限，且新树前 5 年吸碳低 |
| "电是干净的，多用没关系" | 中国 60%+ 电力来自煤电，用电 ≈ 间接烧煤 |
| "塑料袋是最大反派" | 塑料碳问题被高估，牛肉/航空/采暖才是大户 |
| "节能 = 受苦" | 80% 低碳行为是顺手而非牺牲 |

## §5 五个环节的实施详案

### 环节 1 · 开场：碳侦探出动！（30min · 教室）

#### 【活动简述】
通过"行为卡片碳排放排序游戏"和教师/学校先做的可见承诺，破除 5 年级学生对"低碳"的 5 个常见前概念，把"低碳是口号"的认知拉到"低碳要算账"的思维起点，引出全日驱动问题"我们校园到底排了多少碳？我们能改变什么？"

#### 【组织实施】

**0-8min · 校长/班主任开场承诺**

教师走到讲台前，先不说"今天我们要学低碳"，而是说：

> "同学们，在今天活动开始前，老师/学校先做一件事。今天一整天：（举例）教师办公室不开空调；食堂只准备 8 分饱的米饭，不够再加；老师和同学一样用自己的水杯，不领瓶装水。这是我们大人先做的事。然后，我们才有资格和你们一起讨论低碳。"

把承诺写在黑板上，可视化、可验证。

**8-20min · 卡片分类游戏**

黑板分"高碳行为 | 低碳行为"两栏。20 张行为卡片随机发给 6 组：
- 真高碳：开空调 26°C / 吃一顿牛肉饭 / 私家车 5km / 长流水洗碗 / 长明灯
- 真低碳：自带水杯 / 走楼梯 / 关闭打印机不待机 / 旧本子双面用 / 吃本地秋菜
- 干扰项（破前概念）：呼吸 / 放屁 / 多种树 / 用纸袋代替塑料袋 / 多用电

每组上台贴卡片到对应栏，并用 1 句话说理由。

**20-28min · 教师揭示真实数据**

- "呼吸"：人呼出的 CO₂ 来自吃的食物，在自然碳循环里。低碳针对**烧化石燃料**释放的"超额碳"。**呼吸不算高碳**。
- "多种树"：一棵成年树一年大约吸 18kg CO₂；一辆汽车开 100km 大约排 20kg。**多种树是好事，但抵消不了多开车**。
- "纸袋代塑料袋"：纸袋造纸要砍树+耗水+烧能源，全生命周期碳可能比塑料袋还高。真正低碳是**重复使用同一个袋子**。
- "多用电"：中国 60%+ 电来自煤电，**用电 ≈ 间接烧煤**。

**28-30min · 引出驱动问题**

黑板上写：

> "今天我们的任务：当一回**碳侦探**。我们要找出：①校园里碳藏在哪？②有多大？③我们能改变什么？"

发"碳侦探"任务卡（A6 小卡），每组 1 张，上面写有今天的 3 个任务环节顺序。

#### 【引导要点】

1. **不要直接说"答错了"**。学生放错栏时问"为什么这么觉得？"，让他们暴露逻辑后用数据修正。
2. **教师/学校承诺必须真实可执行**。临时翻车会全盘否定整个活动。
3. **强调"低碳特指减少 CO₂ 等温室气体排放"**，与"不乱扔垃圾、保护动物"做简短区分。
4. **强制每组每人至少贴 1 张卡片**，避免少数学生垄断。
5. **数据要小要具体**："18kg / 20kg" 这种学生能脑算的数字。

#### 【注意事项】

- 教师**课前 1 周准备承诺方案**，与校方沟通确认可执行。
- 卡片打印+塑封（一次准备可反复使用），约 30min。
- 如果学生提前知道答案（环保家庭背景型），让 TA 扮演"小老师"角色。
- **不发"碳排放计算器"App 链接**——避免注意力转向手机。

### 环节 2 · 探究 A：校园用能地图（40min · 教室+走廊+操场）

#### 【活动简述】
学生 4 人一组带学校平面图、记号笔、便利贴，分组踩点教室、走廊、食堂走廊、办公室区、操场，实地标记每个用电点位（照明、空调、饮水机、打印机、电脑等），用"高/中/低"标签贴在地图上。回教室后用估算参考卡计算"全校待机设备一年浪费的电"。最后组间比较"最让人意外的隐藏耗能点"。

#### 【组织实施】

**0-5min · 任务分发**

每组拿到：
- A3 学校平面图（教师课前打印）
- 彩色记号笔 4 支（红黄绿黑）
- 便利贴 1 叠
- "用能参考卡"（"电脑待机 ~5W / 饮水机 ~100W / 投影仪关机不拔插 ~2W / 灯管开 1h ~36W"）
- 强制角色卡：记录员 / 计时员 / 汇报员 / 采访员

教师讲明路线：教室 → 走廊 → 食堂走廊（不进后厨）→ 办公室区（敲门进入 1-2 个）→ 操场。

**5-25min · 分组踩点**

20min 踩点，每个用电点位用记号笔标记：
- 红色：高耗能（持续开 / 大功率）
- 黄色：中耗能（间歇开 / 中功率）
- 绿色：低耗能（已关 / 小功率）
- 便利贴：关键发现（"这台电脑下班没关""饮水机一直保温""走廊灯白天还开着"）

教师在路线上巡视 2-3 个关键点。

**25-35min · 回教室估算**

每组用待机能耗估算表：

| 设备 | 待机功率 | 全校估算数量 | 一年待机小时 | 全年浪费电（千瓦时） |
|------|---------|-------------|------------|------------------|
| 电脑 | 5W | 30 | 8760 | __ |
| 投影仪 | 2W | 20 | 8760 | __ |
| 饮水机 | 100W | 10 | 24×30×12 | __ |

最终换算：1 千瓦时 ~0.5kg CO₂；1 棵成年树年吸 ~18kg。算出"全校待机一年 = 多少棵树"，写在地图正中央。

**35-40min · 组间快速比较**

每组汇报员 30 秒说 1 件"最让人意外的隐藏耗能点"，黑板汇总成"碳侦探发现榜"。

#### 【引导要点】

1. **单次只引入 1 个变量**——本环节只标"用电点位"，不混入水/纸/食物。
2. **估算给参考值卡**——5 年级不会自主估算"全校多少台电脑"，要写"假设 30 间教室、每间 1 台"作为脚手架。
3. **不纠结绝对精确**——数量级感比精确数字重要。
4. **办公室踩点要敲门**——课前与办公室老师打招呼配合。
5. **如果学生发现"老师办公室长明灯"**——这是好事！鼓励他们写便利贴，呼应"反向监督"角色。

#### 【注意事项】

- **食堂区不进后厨**——全程在走廊外观察。
- **踩点路线提前 1 周与后勤、办公室对接**。
- **平面图 A3 大小最佳**——A4 太小，A2 太大。
- **如果没有现成平面图**——用百度地图截图 + 教师手绘标注。
- **天气**：本环节 5min 户外（操场段），秋季 10 月适宜。
- **20min 踩点过紧**——可延至 25min，相应压缩估算为 5min。

### 环节 3 · 探究 B：食堂碳侦探 [全天专属]（40min · 食堂）

#### 【活动简述】
学生在午餐前后于食堂残食台旁，分组用电子秤称量本班/本年级剩饭剩菜总量，拍照记录"最常被剩下的菜"。回教室画"今日午餐食物里程地图"，把食材产地标在世界地图上，对比"邻居家产"（京郊）vs"远渡重洋"的距离与碳排放。把"低碳"从抽象概念落到学生每天经历的"吃饭"，呼应世界粮食日（10/16）。

#### 【组织实施】

**11:30-11:45 · 进食堂前的科普（15min · 教室）**

教师展示 3 张对比图：
- 一斤牛肉的碳足迹 ~27kg CO₂
- 一斤白菜的碳足迹 ~0.4kg CO₂
- 一份从澳大利亚运来的车厘子 vs 一份京郊苹果（运输碳排放对比）

讲解 1 个关键概念："食物里程"——食物从产地到我们餐桌的距离。距离越远，运输碳排放越多。

**11:45-12:30 · 午餐时段称量（45min，含吃饭）**

学生先正常吃午餐（约 25min）。吃完后分 2 组（一次只让 2 组进食堂，避免拥挤），每组 4 人：
- 1 称重员（戴手套，分类堆出剩饭）、1 记录员（填表）、1 拍照员（用平板）、1 观察员（数最常被剩的菜）

称重表：

| 类别 | 重量（kg） | 主要内容 |
|------|----------|---------|
| 剩米饭 |  |  |
| 剩肉菜 |  |  |
| 剩素菜 |  |  |
| 剩汤 |  |  |

**12:30-13:00 · 食物里程地图（30min · 教室）**

教师提前从食堂索取**今日午餐 4-5 种食材的产地清单**（"白菜 - 北京大兴 / 米 - 黑龙江五常 / 牛肉 - 内蒙古赤峰 / 油 - 加拿大 / 番茄 - 山东寿光"），打印卡片。

学生在 A3 世界地图上用红线连接产地与北京，估算运输距离（教师提供参考表），算"今天我们的午餐总共'走'了多少公里？"

**13:00-13:10 · 组间分享（10min）**

每组汇报员 1 分钟：哪个食材最远？哪个最近？如果只吃北京周边的食材，菜单会变成什么样？

#### 【引导要点】

1. **不要批判"剩饭"**——5 年级敏感于被指责。称量是"了解事实"，不是"抓现行"。
2. **食物里程不等于唯一答案**——本地不一定永远低碳（如冬季本地大棚耗能可能高于南方运来）。引导理解"复杂系统没有简单答案"，但**作为一般原则，本地食物里程更低**。
3. **称量数据要可视化**——"剩 3kg 米饭 = 30 个馒头 = 全班一天的米"。
4. **避免"光盘行动 = 必须吃完一切"的口号**——强调"按需取餐 + 不浪费"，不是"吃光"。

#### 【注意事项】

- **必须提前 1-2 周与食堂主任沟通**——食堂同意 + 提供产地清单 + 协调时段，是硬前提。
- **卫生防护**：手套、洗手液、塑料围裙各 8 套。
- **称量在午餐后进行**，避免影响其他班级用餐。
- **2026 年 10/16 为周五**——若锚定该日，提前确认是否与学校其他活动冲突。
- **半天版替代**：本环节压缩为"食物里程卡片游戏"（5min），并入环节 2 收尾——给 6 组每组 5 张食材卡片，按"产地远近"排序，公布答案。

### 环节 4 · 实践：落叶里的碳秘密（40-60min · 操场+教室）

#### 【活动简述】
学生到操场分组采集不同树种的落叶（银杏 / 元宝枫 / 法桐 / 国槐），用电子秤分类称重。教师讲"落叶的两种命运"——焚烧（每千克干叶 ~1.5kg CO₂）vs 堆肥（碳留在土里成肥）。回教室后分组选做：A) 简易堆肥小箱搭建 + 留观察任务 / B) 落叶书签制作（写一句给秋天的话）。

#### 【组织实施】

**0-5min · 引子（教室）**

教师展示一张北京市园林绿化局"落叶缓扫"政策公告（2018 年起朝阳、海淀部分公园试点）。问："为什么不扫走？落叶到底是垃圾还是宝藏？"

不直接给答案，让学生带着问题出门。

**5-20min · 操场分组采集（15min · 操场）**

每组分配 5m×5m 区域，准备塑料袋 + 手套。角色：采集员 / 称重员 / 分类员 / 记录员。

| 树种 | 落叶重量（kg） | 状态（干/湿） |
|------|--------------|--------------|
| 银杏 |  |  |
| 元宝枫 |  |  |
| 法桐 |  |  |
| 国槐/其他 |  |  |

教师巡视，提示"不踩花坛""不采树上的""注意脚下"。

**20-30min · 回教室科普"落叶的两种命运"（10min）**

教师在黑板上画两条命运线：

```
落叶
 ├──> 集中焚烧/填埋 → 释放 CO₂（每 kg 干叶 ~1.5kg CO₂）→ 进入大气
 └──> 堆肥/还田 → 微生物分解 → 一部分碳变成腐殖质留在土里 → 滋养植物 → 形成"碳汇"
```

用学生刚称的数据算："我们组 1 小时采了 2kg 落叶，全校一周 100kg：焚烧 = 排 150kg CO₂ = 一辆车开 800km。堆肥 = 碳留下 + 减少买化肥的钱 + 减少化肥碳排。"

**30-50min · 分组选做（20min）**

教室前后两端布置 A/B 两区，学生自选：

**A 区：简易堆肥小箱搭建**
- 物料：废纸箱 + 落叶 + 厨余菜叶（可选）+ 喷壶
- 流程：纸箱底部打孔 → 一层落叶 → 撒少量厨余 → 再铺落叶 → 喷水保湿 → 标注日期+小组名
- 留观察任务：堆肥箱放教室角落，每周 1 组轮流观察记录（温度、湿度、变化），共 4 周

**B 区：落叶书签制作**
- 物料：6×15cm 卡纸 + 落叶 + 胶水 + 彩笔
- 流程：选落叶贴卡纸 → 背面写一句"给秋天的话"或"我对低碳的一个发现"
- 完成后串孔挂在教室"低碳树"展示墙

**50-60min · 总结（10min）**

每组各派 A 区代表 + B 区代表上台：A 代表说"堆肥能减多少碳"，B 代表读"给秋天的话"。

#### 【引导要点】

1. **不强求每个学生搞堆肥**——5 年级有动手型/语言型差异，A/B 自由选。
2. **数据要"翻译"到学生能感受的量**——"150kg CO₂ = 一辆车开 800km"比"150kg CO₂"有感。
3. **强调"碳留在土里"的物质循环**——把"碳"具象成"腐殖质 → 滋养植物 → 树又长起来"，对接科学课"物质循环"。
4. **不把堆肥讲成"魔法"**——学生会问"那为什么所有人不堆肥？" 回答"因为需要时间（3-6 周）、空间、知识。但学校 100 个学生 × 每天关注 1 次，是有条件的。"

#### 【注意事项】

- **秋季 10 月下旬至 11 月初落叶量最足**。若 10 月初实施，落叶可能不足——备份：教师课前 1 周用塑料袋收集干叶储备。
- **雨天备份**：当天下雨用"室内分发干叶包"替代户外，缩短至 10min。
- **白果（银杏果）有毒**——明确"只看叶不碰果"，提前清扫银杏树下。
- **过敏问题**：少数学生对花粉/植物过敏，课前问家长，过敏学生改"记录员（戴口罩）"。
- **堆肥箱处置**：研学结束 4 周后老师需安排"开箱观察"，否则成为烂尾任务。可让生物/劳动老师后续接手。

### 环节 5 · 行动：班级低碳公约 + SMART 承诺卡（30min · 教室）

#### 【活动简述】
学生 4 人一组讨论提出 3 条班级低碳公约草案（具体 / 可执行 / 谁在什么时间做什么），全班投票合并成最终 10 条公约，当场打印贴在教室后墙。每人写 1 张个人 SMART 承诺卡 + 7 天打卡格，带回家。

#### 【组织实施】

**0-10min · 小组共创公约（10min）**

教师在黑板上写"公约 3 条标准"：
- **具体**: 不是"爱护地球"，而是"每天午餐后第一个走的人关教室灯"
- **可执行**: 班级条件下能做（不依赖教师特许 / 不依赖买东西）
- **谁在什么时间做什么**: 主语明确

每组用 A4 公约模板（已印好"我们承诺：______ 谁：______ 何时：______"）写 3 条。教师巡视，对模糊的（"少用塑料"）追问"谁？什么时候？多久？"

**10-20min · 全班投票合并（10min）**

教师收齐 6 组 × 3 条 = 18 条贴黑板上编号。每人发 5 张小贴纸（5 票），可投任意 5 条（不能投自己组的）。

10 分钟内完成投票。得票前 10 条形成最终班级公约。

**20-25min · 当场打印张贴（5min）**

教师把最终 10 条录入电脑，用打印模板（A3，含"班级低碳公约"标题 + 10 条 + 全班签名栏）打印 1 份。学生轮流签名，贴在教室后墙。

**25-30min · 个人 SMART 承诺卡（5min）**

每人发承诺卡：

```
[正面]
我，______ ，承诺从今天起，每天做这件低碳小事：
___________________________________________

[背面]
7 天打卡格：周一□ 周二□ 周三□ 周四□ 周五□ 周六□ 周日□
第 7 天回来给老师看，完成 5 天以上 = "碳侦探见习生" → 颁发徽章
```

#### 【引导要点】

1. **追问"谁？什么时候？多久？"**——SMART 落地的关键。模糊的承诺 3 天后归零。
2. **不要让学生承诺"巨大改变"**——"从今天起再也不开空调"是假承诺；"夏天空调温度不低于 26°C"是真承诺。
3. **投票阶段保护"不主流的好想法"**——某条得票低但教师觉得有价值，问"还有谁觉得这条也重要？"给少数派复活机会。
4. **打卡 5 天以上是宽松标准**——5 年级一周连续 7 天执行力有限，5 天已是好成绩。

#### 【注意事项】

- **打印机/打印 U 盘要提前测试**——卡纸会破坏节奏，最坏情况用手写 A3 公约纸。
- **承诺卡标"自愿"**——少数学生不愿公开承诺，允许写"自己的事我自己知道"。
- **教师在 7 天后回收承诺卡**——给"完成 5 天以上"颁发徽章，仪式感是延续动机的关键。
- **徽章可用现成印贴**——纸质徽章约 1 元/枚，30 枚预算 30 元。

## §6 安全 / 卫生 / 伦理

### 总体原则

1. **教师全程在场** — 不允许学生独自在校园其他区域活动
2. **不进入危险区域** — 食堂后厨、配电房、仓库、施工区禁入
3. **不接触不熟悉的物** — 白果、不明野果、不明虫卵不碰不尝
4. **不强制公开承诺** — SMART 卡允许"私下"完成
5. **过敏知情** — 课前 1 周向家长发问卷确认过敏史，过敏学生调整角色

### 伦理边界

- 教师/学校先做承诺（避免 5 年级双标过敏）
- 不"羞辱式"环保（剩饭称量是了解事实，不是抓现行）
- 接纳"不愿公开承诺"的学生
- 不强迫家长配合
- 数据真实性是科学素养底线（不为面子改数字）

### 分环节风险一览（≥5 条）

| 环节 | 风险点 | 应对 |
|------|--------|------|
| 1 | 群体起哄 | 强制每人贴 1 张卡片 |
| 2 | 走散、私拆电器 | 路线对接；只看不动；2 教师巡视 |
| 3 | 卫生交叉、食堂时段冲突 | 手套+围裙；午餐后；提前协调 |
| 4 | 地面湿滑、过敏、白果、虫蜇 | 长袖长裤；过敏改任务；先清白果；备酒精棉 |
| 5 | 承诺被嘲、打印故障 | 标"自愿"；备手写 A3 backup |

## §9 评价方案

### 9.1 评价原则

- **以过程性证据为主**，不进行书面知识测试
- **核心问题**: "学生是否真正在用眼睛观察、用大脑思考、用证据说话？"
- **不评价"是否掌握专业碳知识"** — 评价"是否形成科学探究行为习惯"
- **避免空话** — 不写"过程性评价"4 字了事，必须列具体观察指标

### 9.2 评价表（教师课中填写，4 维度 × 3 等级）

| 维度 | 碳侦探（优秀） | 见习生（合格） | 还需努力 |
|------|-------------|-------------|---------|
| 科学探究 | 准确填写数据、记录完整、有时间戳；区分事实与推测 | 能记录大部分数据，偶有遗漏；偶尔混淆 | 数据记录混乱；只有主观感受 |

## §11 拓展阅读建议（教师备用）

研学不要求学生掌握以下内容，但教师宜了解，以应对追问：

1. **"双碳"目标基本概念** — 碳达峰（2030 年前）/ 碳中和（2060 年前），但**不向 5 年级讲术语**
2. **食物碳足迹排序** — 牛肉 > 羊肉 > 猪肉 > 鸡肉 > 蛋奶 > 豆类 > 蔬菜
3. **建筑能耗占比** — 北方采暖能耗占建筑能耗约 30%
4. **塑料 vs 纸袋的全生命周期** — 一次性纸袋比塑料袋耗能更多，重复使用是关键
5. **"碳汇"概念** — 森林、土壤、海洋是天然碳汇，落叶堆肥也是小型碳汇
6. **儿童环保前概念跨文化普遍存在** — 不只中国学生，国外研究也发现"植树万能""塑料反派"等误解
